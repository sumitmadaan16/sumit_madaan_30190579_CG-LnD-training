# CG AI Launchpad Training Using Playwright

## Repository Overview

This repository contains the assignments, project artifacts, prompts, and learning deliverables created as part of the **Capgemini CG BULT T7 AI Launchpad Training** program.

The objective of this training was to gain hands-on experience with Generative AI, Prompt Engineering, LangChain, AI Agents, and QA automation use cases powered by AI.
